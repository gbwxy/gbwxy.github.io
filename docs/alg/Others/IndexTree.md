# Index Tree 
Index Tree (树状数组 / Binary Indexed Tree / Fenwick Tree)
解决的问题： 主要用于解决在 数组或序列中需要频繁进行单点更新和区间求和 的问题。
具体应用：
快速计算前缀和： 在 O(log n) 的时间复杂度内计算数组从开始到任意位置的前缀和。
快速计算区间和： 利用前缀和的性质，可以在 O(log n) 的时间复杂度内计算数组任意给定区间（[l, r]）的和（通过 sum(r) - sum(l-1)）。
支持单点更新： 在 O(log n) 的时间复杂度内修改数组中某个元素的值，并自动维护前缀和的信息。
相比普通数组：
普通数组求前缀和很快（O(1)），但单点更新后需要 O(n) 的时间来更新所有受影响的前缀和。
普通数组单点更新很快（O(1)），但区间求和需要 O(n) 的时间来遍历。
树状数组在这两个操作上都达到了 O(log n) 的效率，是一种很好的平衡。
原理： 利用了数字的二进制表示，通过巧妙的设计，每个节点存储的不是一个元素的原始值，而是某个特定区间的和。通过对索引进行位运算（特别是 lowbit 操作），可以快速定位到需要更新和查询的节点。
