# AC 自动机 (Aho-Corasick Automaton)
解决的问题： 主要用于解决 多模式匹配 问题，即给定一个主文本串和一个包含多个模式串（关键词）的集合，需要在主文本串中快速找到所有模式串出现的所有位置。
具体应用：
关键词过滤或查找： 在一段文本中查找所有敏感词或特定关键词。
入侵检测系统 (IDS)： 检测网络流量中是否包含已知的攻击特征字符串。
生物信息学： 在 DNA 序列中查找匹配的模式。
相比多次 KMP： 如果有 M 个模式串，每个模式串平均长度为 m，主文本长度为 N。如果对每个模式串单独使用 KMP 算法进行匹配，总时间复杂度可能接近 O(M * N)。AC 自动机可以将匹配过程优化到接近 O(N + 所有模式串总长度 + 匹配次数) 的时间复杂度，效率大大提高。
原理：
构建 Trie 树： 将所有的模式串构建成一个 Trie（字典树）。
构建失败指针 (Failure Links)： 为 Trie 树上的每个节点构建一个“失败指针”。失败指针指向在当前匹配失败时，应该跳转到的 Trie 树中的另一个节点，以继续匹配，避免从头开始。这个过程类似于 KMP 算法中的“next”数组。
沿着 Trie 树和失败指针进行匹配： 遍历主文本串，同时在构建好的 AC 自动机（Trie + 失败指针）上移动。如果在某个节点匹配成功一个模式串的结尾，就记录下来。如果当前字符无法匹配，就沿着失败指针跳转，直到找到可以匹配的节点或回到根节点。
简单来说，树状数组用于解决数值序列的动态维护和区间查询问题，而 AC 自动机用于解决字符串的多模式高效查找问题。
