## 二进制

### 正数表示
1. 使用原码表示法
2. 最高位为符号位（0表示正）
3. 剩余位表示数值
例如：+5 的8位二进制表示为 `00000101`

### 负数表示
计算机使用补码表示法：
1. 原码：最高位为1（表示负），其余位表示绝对值
   - 例：-5的原码为 `10000101`
2. 反码：符号位不变，数值位按位取反
   - 例：-5的反码为 `11111010`
3. 补码：反码 + 1（最终存储形式）
   - 例：-5的补码为 `11111011`

### 补码优势
1. 统一加减法运算（不需要单独处理负数）
2. 消除+0和-0的歧义（补码表示中0只有一种形式）
3. 扩展表示范围（n位补码可表示-2^(n-1)到2^(n-1)-1）

### 小数表示（浮点数）
计算机采用 IEEE 754 标准：
1. 单精度（32位）：
   - 符号位（1位）：0正1负
   - 指数位（8位）：实际指数 = 指数值 - 127
   - 尾数位（23位）：隐含最高位1（规范化形式）
   例：-13.625 的二进制表示为：
   `1 10000010 10110100000000000000000`

2. 双精度（64位）：
   - 符号位（1位）
   - 指数位（11位）：实际指数 = 指数值 - 1023
   - 尾数位（52位）
   
转换步骤：
1. 将小数转换为二进制科学计数法（例：13.625 = 1101.101 = 1.101101×2³）
2. 计算指数偏移值（单精度：127+3=130 → 10000010）
3. 组合符号位、指数位、尾数位（去掉前导1）

### 特殊值表示
- 0：指数和尾数全0
- 无穷大：指数全1，尾数全0
- NaN：指数全1，尾数非0

### 位运算
1. 按位与（&）：对应位都为1时结果为1，否则为0
   - 例：`101 & 110 = 100`
2. 按位或（|）：对应位至少有一个为1时结果为1，否则为0
   - 例：`101 | 110 = 111`
3. 按位异或（^）：对应位不同时结果为1，否则为0
   - 例：`101 ^ 110 = 011`
4. 按位取反（~）：将所有位取反（0变1，1变0）
   - 例：`~101 = 010`
5. 左移（<<）：将所有位向左移动指定数量的位置，右边补0
   - 例：`101 << 2 = 10100`
6. 右移（>>）：将所有位向右移动指定数量的位置，左边补符号位（正数补0，负数补1）
   - 例：`101 >> 2 = 001`
   - 例（8位）：`-5（11111011）>> 2 = 11111110（-2）`
7. 无符号右移（>>>）：将所有位向右移动指定数量的位置，左边补0
   - 例：`101 >>> 2 = 001` 
   - 例（8位）：`-5（11111011）>>> 2 = 00111111（127）`
### 位运算应用
1. 清零：将某一位或某几位清零
   - 例：`101 & ~(1 << 2) = 001`
2. 取指定位：将某一位或某几位保留，其余位置零
   - 例：`101 & (1 << 2) = 001`
3. 测试某一位是否为1：将某一位与1进行按位与操作
   - 例：`101 & (1 << 2) != 0`
4. 交换两个数：使用异或操作
   - 例：`a = a ^ b; b = a ^ b; a = a ^ b;`
5. 计算绝对值：对于负数，将其按位取反后加1
   - 例：`-5的绝对值为 ~(-5) + 1`
6. 快速幂运算：使用位运算代替乘法和除法
   - 例：`2^10 = (2^5) * (2^5)`
7. 位掩码：用于提取、设置或清除特定位置的位
   - 例：`101 & 011 = 001`
### 位运算注意事项
1. 溢出问题：在进行位运算时，要注意结果是否会超出数据类型的范围
2. 符号问题：在进行位运算时，要注意符号位的影响
3. 优先级问题：在进行位运算时，要注意运算符的优先级
4. 无符号数：在某些情况下，可能需要使用无符号数进行位运算
5. 位运算效率：位运算通常比其他运算效率更高，但在可读性和可维护性方面可能不如其他运算


### 相反数

#### 计算方法
1. 正数变负数：按位取反后加1（补码）
   - 例：+5（00000101）→ 取反得11111010 → 加1得11111011（-5）
2. 负数变正数：同样操作（补码的补码等于原数）
   - 例：-5（11111011）→ 取反得00000100 → 加1得00000101（+5）

#### 代码实现
```c
int reverseNumber(int num) {
    return ~num + 1;  // 按位取反加1
}
```
#### 特殊情况
1. 零的相反数：0的补码仍然是0
2. 最小值溢出：对于8位有符号数（范围-128~127），-128的相反数无法表示
   - 例：-128（10000000）→ 取反01111111 → 加1得10000000（仍然是-128）
