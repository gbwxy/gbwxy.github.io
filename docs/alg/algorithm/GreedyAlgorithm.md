# 贪心算法

## 算法思想

贪心的本质是选择每一阶段的局部最优，从而达到全局最优。

## 一般解题步骤

- 将问题分解为若干个子问题
- 找出适合的贪心策略
- 求解每一个子问题的最优解
- 将局部最优解堆叠成全局最优解
